Services

Content · Self-hosted Docker
Ghost CMS
cms.tlrhd.com/ghost

The single source of truth for all published content. Deep-dive studies use tag deep-dive, Sunday messages use tag sunday-message. New posts flow to the site automatically through the sync.

Docker admin login required cms.tlrhd.com
Hosting · Cloudflare Pages
CF Pages — Live Site
tlrhd.com

Hosts the static site and auto-deploys whenever the main branch receives a new commit — including the JSON files written by GitHub Actions every 2 hours. No manual deploy needed.

auto-deploy on push static free tier
Proxy · Cloudflare Workers (×2)
ghost-proxy & yt-proxy
ghost-proxy.reinar-6fd.workers.dev

Two Workers act as API bridges. ghost-proxy lets browser JS reach Ghost without CORS errors and bypasses the WAF firewall via a shared secret. yt-proxy fetches YouTube channel data.

CORS WAF bypass ghost-proxy · yt-proxy
Source code · GitHub
GitHub Repo
github.com/reinarrr/TLR-web-cfpages

All HTML, CSS, and JS live here. Also stores the JSON fallback files (messages.json, res/deep/*/deepdives.json) that are auto-committed by GitHub Actions every 2 hours so the site works even if Ghost goes down.

reinarrr/TLR-web-cfpages main branch
Automation · GitHub Actions
Ghost Sync Workflow
github.com/.../actions

Runs scripts/sync-ghost.js every 2 hours. Fetches fresh posts from Ghost CMS, writes updated JSON fallback files, and commits them — which triggers a CF Pages redeploy automatically. Can also be triggered manually.

every 2 hours sync-ghost.yml ghost-sync[bot]
Video · External
YouTube
youtube.com channel

Primary video library for all messages and replays. The site fetches channel data via the yt-proxy Worker. Ghost CMS enriches recent videos with cleaner titles and dates — YouTube is the source of record for the full history.

video hosting full library enriched by Ghost

Data Flow

Live Path — browser

1
Browser opens a page
JS runs in ghost.js / main.js
2
Calls ghost-proxy Worker
ghost-proxy.reinar-6fd.workers.dev
3
Worker fetches Ghost CMS
Adds CORS headers · passes WAF secret
4
Content rendered in browser
Always fresh from Ghost
↩
Fallback: use local JSON
messages.json / deepdives.json if Ghost or Worker is unreachable

Sync Path — every 2 hours

1
GitHub Actions triggers
Cron: 0 */2 * * * · or manual dispatch
2
sync-ghost.js runs
Node 20 · server-side, no CORS restrictions
3
JSON fallbacks written
messages.json · res/deep/{year}/deepdives.json
4
Committed to repo
ghost-sync[bot] pushes to main — only if files changed
5
CF Pages auto-redeploys
New commit triggers build · tlrhd.com updated within ~30s
